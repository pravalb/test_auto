# Created by Muhammad Arsalan for Hilal Softwares End-to-End Automation Framework built with JavaScript and Playwright, integrated with Allure Reporting.

### This project contains automated tests for Hilal Softwares’ Chatbot Widget using Playwright with JavaScript. The framework is built on the Page Object Model (POM) design pattern to ensure maintainability and scalability of test scripts. The tests are executed in both UI and Headless modes, with detailed test execution results generated through Allure Reports. Version control and code deployment are managed via GitHub.

## Dev Dependencies

@playwright/test
 * ^1.55.0 (Test runner and automation library)

@types/node
 * ^24.4.0 (TypeScript type definitions for Node.js)

allure-playwright
 * ^3.4.1 (Allure reporting integration with Playwright)

dotenv
 * ^17.2.2 (Environment variable management)
